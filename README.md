# Legacy Fullstack Refresh

Цей репозиторій створений для роботи з навчальними проєктами, які були отримані під час онлайн-курсів з fullstack-розробки (HTML, CSS, JavaScript, Node.js, Handlebars, React тощо).

## Що це за проєкт

- Початковий код був створений у рамках навчання в онлайн-школі.
- Частина структури та шаблонів — **legacy** (застарілий підхід, старі версії пакетів та інструментів).
- Моє завдання — **акуратно перенести цей код**, поступово **оновити стек**, структуру та інструменти:
  - Node.js
  - npm-скрипти
  - ESLint / Prettier
  - Webpack
  - шаблонізатор Handlebars
  - структуру папок

## Мета

- Перетворити навчальний шаблон зі школи на **сучасний навчальний fullstack-проєкт**.
- Тренувати:
  - роботу з Git (гілки, коміти, історія)
  - оновлення залежностей без “ламання” проєкту
  - рефакторинг legacy-коду
  - структурування оточення (environment) для майбутніх власних проєктів.

## Legacy-частина

- Початкові файли (`app.js`, `index.js`, Handlebars-шаблони, конфіги) розглядаються як **legacy база**.
- У процесі я:
  - переношу код у нову структуру
  - поступово оновлюю залежності
  - документую зміни в комітах

## Технології (на старті)

- Node.js (старі версії на базі навчальних проєктів)
- Express
- Express-Handlebars
- Webpack
- ESLint + Prettier (старі конфіги)

## Плани розвитку

- Оновити залежності до стабільних більш актуальних версій (без фанатичного “все в останню версію”).
- Поступово оновлювати конфігурації:
  - `package.json`
  - `webpack.config.js`
  - `.eslintrc.json`
  - `.prettierrc`
- Додати більш складні приклади:
  - сторінки з даними
  - інтеграцію з фронтенд-практиками
  - окремі гілки під експерименти.
